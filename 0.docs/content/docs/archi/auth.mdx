## Kubernetes

Mise en place d'un serveur DEX en ten qu'intermédiaire pour l'authentification OIDC avec l'api Kube.

Il est possible qu'in finé DEX ne soit pas la bonne solution vis a vis d'Eclipse Che qui pourrait ne pas supporter DEX en tant que provider OIDC, dans ce cas il faudra trouver une autre solution d'authentification OIDC compatible avec Eclipse Che et Kubernetes (Retour a la configuration de base).
