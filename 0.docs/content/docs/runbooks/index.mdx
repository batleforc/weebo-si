title: Runbooks
description: "Procédures pas à pas pour les opérations sensibles du cluster"
---

Un runbook décrit une opération qu'on ne fait pas tous les jours, étape par étape, avec ses vérifications et son retour arrière. Il est écrit pour être suivi tel quel, terminal ouvert à côté.

Chaque runbook suit la même forme :

1. **Avant de commencer** : prérequis et sauvegardes.
2. **Étapes** : une action par étape, suivie de ce qu'il faut vérifier avant de passer à la suivante.
3. **Retour arrière** : comment revenir à l'état précédent si une vérification échoue.
